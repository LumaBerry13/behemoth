# Behemoth particle library

Shared particles built into the framework's resource pack (`packs/behemoth/RP/particles/`), so every boss pack can
use them without shipping particles of its own. They are generated by [`tools/particles.py`](../tools/particles.py)
(`python tools/particles.py` rewrites them; a test checks the committed files are current). Textures are white
(`RP/textures/behemoth/particles/`), so the colour you pick is the colour you see.

## Particles

| Id | Looks like | Main options (defaults) |
| --- | --- | --- |
| `bhm:dust` | Small coloured dust point (MythicMobs `dust` / `reddust`) | `color` (red), `size` 0.08, `lifetime` 20 |
| `bhm:dust_transition` | Dust that shifts from `color` to `color2` (MythicMobs `dust_color_transition`) | `color` (cyan), `color2`, `size` 0.08, `lifetime` 20 |
| `bhm:spark` | Burst of bright sparks flying out and falling | `color` (gold), `amount` 8, `speed` 5, `size` 0.06, `lifetime` 10 |
| `bhm:smoke` | Soft puffs that rise and grow | `color` (grey), `amount` 3, `rise` 1, `size` 0.3, `lifetime` 30 |
| `bhm:glow` | Glowing, gently pulsing orb | `color` (light blue), `size` 0.25, `lifetime` 12 |
| `bhm:flash` | Big short flash | `color` (white), `size` 1.5, `lifetime` 5 |
| `bhm:ring` | Flat ring on the ground expanding to `size` blocks (shockwave) | `color` (white), `size` 3, `lifetime` 12 |
| `bhm:telegraph` | Flat pulsing warning circle of radius `size` | `color` (red), `size` 3, `lifetime` 20 — use the `telegraph` mechanic |
| `bhm:swirl` | Particles spiralling upward (tornado, summoning circle) | `color` (purple), `amount` 24, `width` 1.5, `rise` 2, `speed` 360 (°/s), `size` 0.07, `lifetime` 24 |

## Options

Every particle-drawing mechanic (`particle`, `particleRing`, `particleSphere`, `particleLine`) accepts these next to
`particle`. `projectile` and `rayTraceTo` take them inside `particleOptions: { ... }`, because their own `speed` and
`radius` mean something else. Vanilla particles ignore them.

| Option | Meaning | Molang variable |
| --- | --- | --- |
| `color` | `"#RRGGBB"` or `"#RRGGBBAA"` | `variable.color` |
| `color2` | End colour (`bhm:dust_transition`) | `variable.color2` |
| `size` | Half-size in blocks; radius for `bhm:ring` / `bhm:telegraph` | `variable.size` |
| `lifetime` | Ticks | `variable.lifetime` (seconds) |
| `speed` | Blocks/second (`bhm:spark`), degrees/second (`bhm:swirl`) | `variable.speed` |
| `amount` | Particles per spawn | `variable.count` |
| `rise` | Upward speed, blocks/second (`bhm:swirl`, `bhm:smoke`) | `variable.rise` |
| `width` | Swirl radius, blocks | `variable.radius` |

```js
{ m: "particle", o: { particle: "bhm:dust_transition", color: "#00FFFF", color2: "#0066CC", count: 8, spread: 1 } }
{ m: "particle", o: { particle: "bhm:ring", color: "#FF8040", size: 5, lifetime: 12 }, t: "@SelfLocation" }
{ m: "telegraph", o: { radius: 3, duration: 30, color: "#FF3030" }, t: "@TargetLocation" }
{ m: "projectile", o: { particle: "bhm:glow", particleOptions: { color: "#80E0FF", size: 0.3 }, onHit: "hit" } }
```

The test boss has `demo_particles` (every particle) and `demo_telegraph` (a telegraphed hit): cast them from
`/behemoth` → Bosses in world → Test Boss → Skills.

## Adding a particle

Add an entry to `PARTICLES` in `tools/particles.py` (reuse the helpers so the shared variables and defaults keep
working), run `python tools/particles.py`, list it here, and use it from a demo skill.

[VERIFY] in-game: materials `particles_add` / `particles_blend`, flat facing mode `emitter_transform_xz` (ring,
telegraph), and that Molang variables passed at spawn reach particle-level expressions.
